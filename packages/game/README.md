# @chillbuilder/game

The core game: Phaser 4 + TypeScript, built with Vite. See the repo root README and the plan doc for architecture and milestones.

## Scripts

- `npm run dev` — start the Vite dev server (http://localhost:8080)
- `npm run build` — production browser build to `dist/`
- `npm run typecheck` — TypeScript check with no emit
- `npm run test` — run Vitest unit tests
